六段链路说明

新增 / 编辑口令

「口令」= 一条可复用的取数凭据。端点模板里的 {code} 会被替换成口令码；也支持直接填完整 URL。请求统一走 fm.req（Native OkHttp，无 CORS）。

口令库

获取口令数据

选中口令后点「拉取」；离线演示请用「拉取演示样本」。原始响应会存成一条数据集，可反复解析、重新生成站点。

离线导入 / 粘贴原始数据

数据集

站点管理

从数据集归一化出的统一站点记录。启用后可注入到 App（/manage/csp 站点注入）成为真正可点播的站点；也可复制配置自行粘贴。

站点列表

运行站点

两条运行路径：原生运行 交给 App 的 Spider 引擎（fm.search / fm.vod）；页内运行 用 fm.req 取回页面并解析出可播放条目，作为兜底与预览。

运行结果

桥接 App 播放器

按 URL 类型自动路由：直链 → fm.play；网盘 / 磁力 → fm.pan.play；多集 → fm.vodInline。播放前会把海报映射写进 fm.cache，便于最近观看恢复。
